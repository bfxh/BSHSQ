# PLAN：**三角形作为一等几何**（软体线的硬缺口）

> 立项依据：`SURVEY-SOFT-CLOTH-AND-CONVERSION.md` §①（"最硬的缺口不在 XPBD 本身，在三角形一等几何"）
> 与 §8.4.13/§8.4.20（绳↔刚体那一线已闭环，**点链**的能力上限也摸清了）。
> **一句话**：`Shape` 枚举里**没有三角网** ⇒ 布片/薄壳/毁坏碎片无法作为**一等几何**参与接触、
> 自碰撞与气动；`vxl-phys-aero` 至今是 28 行纯配置（**无几何输入、无消费方**）。
> 这不是"再写一个求解器"，而是**给几何层补一类形状**。

## 为什么现在做（而不是先做别的）

- 布料那条线的**全部**后续（自碰撞、撕裂、气动、与体的双向）都卡在这一点上；
  2c 那条（绳↔刚体）已经把"点链能做什么"榨干了（点链**没有表面** ⇒ §8.4.1 的"托住"上限）。
- 本仓已有的两块**可复用资产**：`vxl-phys-terrain::TriMesh`（**静态** provider 已通，含 8×8 网格判据）
  与 `vxl-phys-soft` 的 XPBD 最小闭环（结构/剪切/弯曲三组柔度已验）；
  缺的是**动态**三角网与"三角对三角"的接触。

## 判据（**先判据后实现**；每步落地前先能跑）

- **零换代门**：默认档（不创建三角网体时）**既有判据与冻结哈希一字不动** —— 新形状只在被显式创建时生效。
- **① 动态三角网体落得下**：布片（规则网格）落到静态球/盒/provider 上 ⇒ **逐顶点就位间隙 ≈ 0**
  （口径同既有的间距判据）+ 末态**位模式冻结**（debug/release 一致）。
- **② 自碰撞不许自穿**：把布片**折成两半**（两侧相互靠近）⇒ 断言两侧粒子的**最小间距 > 0**、
  且**无粒子穿到对侧**（用平面穿透计数的形式钉住）。**金丝雀**：把自碰撞关掉 ⇒ 同一条判据必须红。
- **③ 面元气动与解析对拍**：给定均匀风速、布片法向已知 ⇒ 稳态受力与 `F = ½·ρ·v²·A·Cd` 对拍，
  容差按离散化给（边层面元的 `Cd` 取平板值，写清取值来源）；同时钉住"无风 ⇒ 零附加力"。
- **④ 与刚体的双向**（薄壳压在体上 / 被体推）：动量守恒口径与 §8.4.20 同款（`body_dv`/`body_dx`
  两条腿 + 睡眠体呈现静态），**不再另发明一套**。

## 代码触点（按依赖顺序）

1. **几何层加一类形状**：`Shape` 里加 `TriMesh(Arc<...>)`（或等价的句柄型）——
   ⚠️ **这是本计划唯一"编译面很大"的一步**（全仓 `match Shape` 的站点都要补分支，
   现有 `_ => None` 兜底的地方要改成"如实不支持/如实支持"）。
   与 `Compound` 的先例对齐：**按形状走"支持矩阵"**，不支持处显式返回 `None`（不是 panic、不是静默）。
2. **质量属性**：薄壳的 `mass_props`（面积×厚×密度、薄壳惯性）—— 与 `core::mass` 的既有三档并列。
3. **宽相**：AABB 由顶点聚合（已有 `bounding_sphere_radius` 同族做法可参照）；大网格别每帧重算
   （脏标记）。
4. **窄相**：先做**点-三角**（顶点 vs 三角，判据 ① 就够用）→ 再做**边-边**（判据 ② 需要）。
5. **软体侧**：`ClothSheet` 从"规则网格的内存结构"升级为"**带拓扑的网格**"（顶点 + 三角 + 邻接），
   自碰撞用**空间哈希**（本仓已有网格向量化的先例）；气动放 `vxl-phys-aero`（把 28 行配置变成消费方）。

## 分步与回退（每步独立、可单撤）

| 步 | 内容 | 落地判据 | 回退 |
|---|---|---|---|
| **T1** | `Shape` 加三角网 + 质量属性 + 宽相 | 零换代门 + ① | 单提交撤销；默认档不创建该形状 ⇒ 恒等 |
| **T2** | 窄相"点-三角"（顶点 vs 静态球/盒/provider 之外的形状） | ① 的加强档 | 同上 |
| **T3** | 自碰撞（空间哈希 + 点/边/面三对，最小档） | ②（含金丝雀） | 同上；自碰撞是**开关**（默认关） |
| **T4** | 面元气动（风 → 每面力/力矩） | ③ + ④ | 同上；气动是**开关**（默认关）。**③ 已落地（2026-09-28，`aero_face_forces.rs`：静板读数逐字=解析 / 零风逐位零金丝雀 / 漂移对拍）；④ 待做** |

## 风险

- **风险 A（枚举扩散）**：`Shape` 加分支会碰到全仓的 match；**先做一遍"形状支持矩阵"普查**，
  把不支持处**显式化**（如实返回 `None`），别留下静默路径。
- **风险 B（自碰撞成本）**：O(n²) 起步在 1k 顶点就不可用 ⇒ 必须空间哈希；
  并且自碰撞是**开关**（默认关），免得既有场景被拖慢。
- **风险 C（气动口径）**：平板 `Cd` 与"面元法向"在不同文献里口径不同 ⇒ 判据里**写清取值来源**，
  并与解析式对拍（不是与"另一个实现"对拍）。
- **风险 D（薄壳的数值刚性）**：薄壳 + 小厚度会让接触的 `ω·dt` 变大 ⇒ 角反作用那三件
  （§8.4.29/§8.4.30/§8.4.31）在薄壳上要**重跑一遍**，别假设绳上验过就成立。

## 边界（不做什么）

- **不做**布料撕裂/塑性/湿-干（后续切片）；
- **不做**三角网与 provider 的**双向**（provider 仍是静态几何）；
- **不做** GPU 档（先把 CPU 档的判据立起来）；
- **不做**"三角形一等几何"之外的重构（求解器仍是顺序冲量 + XPBD，不动）。

## 外部对标与护栏（先算账，别照抄）

- **同类做法**：XPBD 系列（Müller 2020 等）里布片本就是**三角网 + 顶点/边/面三层碰撞**；
  Jolt 的软体、Bullet 的 `btSoftBody`、PhysX 的布料同族（都是"网格 = 一等几何"）；
  Rapier 至今**没有**布料/软体 ⇒ 本仓的"单求解器 + 域通道"结构与其不同，不能直接抄它的分层。
- **护栏**：外部这么做**不等于**本仓成立 —— 本仓已否证的相邻路线有：把绳索做成"胶囊链 + 距离关节"
  （实测 NaN 爆炸，§③）、"减指令数"六连否、求解环五种布局全否（见 `PERF-REVIEW` 那页的"勿重做"清单）。
  ⇒ 本计划**只借结构（网格是一等几何）**，不借实现（碰撞层次/迭代口径按本仓判据重验）。

## 优先级重排（写清，别只堆新计划）

1. **2c-3 的默认翻转**（绳↔刚体）：**测量已齐**（§8.4.32：开着照旧托住、只是轻微摇晃），
   代价是重冻软体域那几条基线并登记 ⇒ **等维护侧一句话**即可落地。
2. **本计划 T1**（三角网进 `Shape`）：它是布料那条线的**唯一前置**，也是"薄壳"这类真实需求的门。
3. **体素↔多边形转换的物理四件**（`StateBridge` 该落的位置）：与本计划**并列**，
   但它没有"几何缺口"挡路 ⇒ 想先出可见成果可以走它。
4. 其余（GPU 档接触/解算切片、自碰撞的进阶档、撕裂/塑性）：**排在上面之后**。
