# DESIGN-ccd-rotation —— 自旋体 / 动目标的 CCD 转动缺口该怎么收（2026-10-21 立项稿，待落）

> 一句话：**P18 的"空转顶住"与 P21 的 0.16 m 深命中是同一个病**——重叠在两次解算之间就被造出来了，
> CCD 只是事后反应。本文把证据、三条候选、判据与分片钉死，避免下一次再靠猜。

关联：`OPEN-PROBLEMS.md` P18 / P21、`PLAN-kinematic.md`、`KNOWLEDGE.md` §1.9（棘轮是测量不是豁免）。

## 1. 证据（2026-10-20/21 实测，均在本机复算过）

| 读数 | 值 | 来源 |
|---|---|---|
| 自旋薄片档最深命中 | **0.15948 m**，命中样本 `t≈0.0019 s`（`sub=0.000641` 的 s=3） | `tests/ccd_sweep_stats.rs` ③ + 临时打印（已删） |
| 同一 tick 更早样本 | `depth≈0.1598`、**`vn=+3.1`（分离）** ⇒ 被 `vn < 0` 门挡在命中之外 | 同上 |
| 细采样档（`ccd_fine_sample`）在静态薄墙 | 0.17167 → **0.01480（−91%）** | `diag_fine_sampling` |
| 细采样档在自旋薄片 | **0.15948 不变**（采样 +42%） | 同上 |
| P18 关档刀锋咬入 | 7.8 mm，并把杆弹飞 46.9 m | `tests/ccd_rotational_sweep.rs` |
| P18 开档（现状） | 峰值埋深 0.0000，但 `ω` 不被吸收（"空转顶住"） | 同上 |
| **CCD 扫掠起点 t=0 的窄相** | 该对已是 `depth=0.16097`、`close=+2.55`（分离），叶片/盒两侧一致 | 2026-10-21 临时探针（已删） |

**定性（2026-10-21 决定性读数）**：0.16 的重叠**在 CCD 扫掠开始前就存在且正在分离** ⇒ 它不是"检出滞后"，
是上一子步遗留的**持续穿透**。所以采样密度、命中判据都改不动它（S1 已实测反证）。

**归因（两条，互相独立）**
1. **命中判据**：`eval_hit` 只在 `vn < 0` 时算命中。深重叠里 SAT 的最小轴会翻转 ⇒ 接触点法向速度由负转正，
   于是"最容易停住"的那些样本全被判成"不接近"。这不是采样密度问题（细采样已证明无效）。
2. **重叠是在解算之间造出来的**：自旋目标每子步转 `ω·dt_sub`（20 rad/s、`r≈0.6` ⇒ 0.10–0.2 m/子步），
   离散窄相在子步末才看见它 ⇒ 下一个子步开始时已经是深重叠；CCD 的采样窗口只能"追认"。

## 2. 现状时序（`crates/vxl-phys/src/world_step.rs:347-353`）

```
clamp_flagged(dt_sub) → integrate_positions(dt_sub) → stabilization → ccd_pass(dt_sub)
```

- `ccd_pass`（`world_ccd.rs:26`）只对 `needs_ccd` 的体逐体扫掠；目标姿态已按时间插值（P20）。
- 候选对由 `gather` 用**扫掠 AABB ∪ 体自身转动摆幅**查询（`sweep.rs`），目标侧用**当前（子步末）AABB**。
- 命中后 `resolve` 只做**平动**非弹性停；转动响应有意留白（两种朴素写法都被实测反例挡下，见 P18）。

## 3. 三条候选（按代价从低到高；可叠加，但每片单独验收）

### S1 · 深度感知的命中门（**实测无效，已回退**，2026-10-21）
在 `scan` 的单趟里记住**上一采样该对的深度**（局部变量，不进状态），命中判据从
`vn < 0` 扩成 `vn < 0 || depth > prev_depth + ε`（ε 取 `0.25·skin`，且 `depth > 0`）。
- 触点：`sweep.rs::scan`（单趟、两事件），`eval_hit` 返回值已带 `depth`；无需动 `resolve`。
- 风险：静置体每个采样深度恒定 ⇒ 不触发（`prev_depth` 不减）；滑动接触深度不变 ⇒ 不触发。
- **实测（默认关 vs 开，自旋薄片档）**：samples 268706→262456、hits **126→586（×4.6）**、
  refine **1008→4688（×4.7）**、deepest **0.15948→0.15978（反而更深）**。
- **裁决：无效，代码已回退（未合并）**。原因与 §1 的归因一致：重叠在采样开始前就存在，
  「深度在增长」只会更早撞上同一个深重叠，不可能把 deepest 压下去。⇒ **C1 取消，直接做 C2**。

### S2 · 自旋/运动学目标下沉到子步（真正"别让它形成"；S1 已取消，这是当前唯一可做的切片）
对 `|ω|·r·dt_sub > skin` 的运动学/动态目标，把它的**姿态更新**按 `skin` 分辨率再切（内部子步，
不增加求解器轮次），让窄相在子步末看到的重叠 ≤ 皮肤带。
- 触点：`world_step.rs`（子步内目标推进处）、`world_kinematic.rs`（运动学姿态推进）、`sweep.rs::gather`（目标摆幅）。
- 代价：只有"快转目标"付采样钱；`ω = 0` 的路径逐位不变。
- 判据：S1 后再量同一档 deepest（目标 ≤ 0.02 m）；m0 压力档 p50 退化 ≤ 5%。

### S3 · TGS-Soft 转动响应（终局）
把 CCD 命中后的响应从"平动非弹性停"升级为**接触点冲量 + 软约束**（与离散求解器同一套法向/切向参数），
`ω` 被吸收而不是被钳住。**不采用**P18 里被否证的两种写法：① 只按角向有效质量收口（过冲）；
② 完整点冲量但逆惯量用错（细杆 |ω| 顶到 504）。
- 触点：`sweep.rs::resolve`、`vxl-phys-solver` 的接触有效质量函数（复用，不复制公式）。
- 判据：`ccd_rotational_sweep` 的三种读数（埋深 / 杆心漂 / `|ω|`）同表更新；`|ω|` 不得 > 100 rad/s；
  m0 门槛档翻醒 < 1.0/s；金样与 determinism 按 ADR-0004 重冻。

## 5. 不做的事

- **不**用"提高 `ccd_max_steps`"糊过去：自旋档的深命中与采样密度无关（已实测）。
- **不**在 `eval_hit` 里放宽到"有接触即命中"：贴地滑行会被钳回起点（P18 的既有反例）。
- **不**把转动响应塞进 `resolve` 而不改判据：那是把"钳住"换成"扭爆"，P18 已量过 `|ω|=504`。
