# CPU 布料第三片：每三角面线性相对风力

## 契约

- `ClothSheet::wind: Option<ClothWind>` 默认为 `None`；不设置时旧布料积分路径不变，不遍历三角形。每张布可独立设置风速、空气密度和阻力系数，参数要求有限，密度/阻力非负；零密度或零阻力不产生风力。
- 按 `SPEC.md` §4.7 的线性相对风力口径，对三角形取当前法线和面积、顶点速度均值；只取风-布相对速度的法向分量，`F = 0.5 * density * drag * area * dot(v_wind - v_tri, normal) * normal`，双面受力。把力均分到三个顶点，并按每个顶点的逆质量与子步时长更新速度。面积趋零的面不受风。钉扎节点不响应外力。
- 一个子步内先按稳定三角顺序从未更新的顶点速度累加全部面力，写入复用缓冲，再统一施加；不为每子步分配堆内存。面力作用于已有位置预测/XPBD 约束/静态 provider 接触之前。没有添加刚体反作用、气流遮挡或随机扰动。

## 验收与下一步

- `vxl-phys-soft/tests/cloth_wind.rs`：平面法向风平均速度满足解析值，切向风不做功，反向风反向，零阻力与默认路径逐位相同；钉扎节点和退化面安全。
- `vxl-phys/tests/cloth_wind_scene.rs`：`World` 中有风/无风布片同时步进，交换注册顺序后两个位置摘要各自逐位不变；固定门面哈希与自由边正向抬升。
- 风场只覆盖纯布料面元受力；粒子与刚体代理的有限接触已在 `PLAN-cloth-cpu-body-contact.md` 实施。自碰撞/撕裂仍未覆盖；`World::state_hash()` 只覆盖刚体，不可充当布料身份门。
