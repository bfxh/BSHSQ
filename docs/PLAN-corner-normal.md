# PLAN-corner-normal —— 角点处法线定义（P18 的「窄相法线」路线，2026-10-28 立项稿）

> 一句话：P18 的刀锋「擦过去」不是 CCD 的锅，也不是软接触不够软；**是 SAT 在角点选了柱子的薄轴**
> （b2，穿透 0.0050），而杆自己的薄轴（a2，穿透 0.0281）大 5.6 倍。要让刀锋被卡住，必须改
> **「多个近分离轴里选哪个」**这条规则——这是**模型选择**，不是 bug 修复，所以判据先立、止损先写。

关联：`DESIGN-ccd-rotation.md`（收口后补：M2 软接触已在 M1）、`OPEN-PROBLEMS.md` P18、
`adr/0004`（换代账）、`KNOWLEDGE.md` §1.9（棘轮是测量不是豁免）。

## 1. 现状（可复核的代码位置）

| 环节 | 位置 | 现状 |
|---|---|---|
| 选轴 | `vxl-phys-narrow/src/sat.rs:335` `sat()` | 取 `sep` **最大**（穿透最小）且在 `skin` 内的轴；`best_src` 记 FaceA/FaceB/Edge |
| 盒对快路径 | `sat.rs:254` `box_pair_scan` → `simd::sat_scan` | 4 轴并行扫描，与标量**逐位等价**（`simd::tests::simd_matches_scalar_bitwise` 守门） |
| 接触点 | `sat.rs::clip` + `select.rs` | 参考面裁剪 + 深度降序/并列带去重 ≤4 点 |
| P18 读数 | `tests/ccd_rotational_sweep.rs` | 末态 `min\|φ\| = 3.364°`（柱面 3.274°）、杆心漂 **0.711 m**、`\|ω\|` 10.13 |

六轴穿透（P18 稳态 t=239，`DESIGN-ccd-rotation.md` 末表）：a2 = **0.0281**、b2 = **0.0050**，
次小轴比 b2 大 5.6× ⇒ 当前法线就是 b2 方向，**SAT 没选错**，只是"最小穿透"这条规则在角点给出的是
"擦过去"的解。

## 2. 候选规则（三条，按侵入性排序；每片单独 A/B，默认关）

### C1 · 角点带偏好（`corner_band`）
在 `sat()` 的选轴循环里加一个**带**：当某个**面轴**的 `sep` 落在 `best + band` 之内、
且它的来源是**另一侧**（FaceA vs FaceB 互换）时，按固定优先级选它（例如「FaceA 优先于 FaceB」
或「薄轴所属体优先」）。

- 触点：`sat.rs` 标量循环 + `box_pair_scan`（**必须同口径**，否则 `simd_matches_scalar_bitwise` 红）。
- 参数：`PhysConfig::corner_band: f32`（米，默认 0.0 = 关 ⇒ 逐位不变）。
- 风险：带内选择会改变大量密堆接触（b2/a2 量级接近的对很多）⇒ 换代面大。

### C2 · 角点特征识别（几何，不看速度）
只有当**最小轴是 B 的面轴**、且 A 的最深点在 B 该面的**矩形边界之外**（即真正的"角点/棱"接触）时，
把法线改成「A 的最深点到 B 该面最近边界点的方向」（角点法线），而不是面法线。

- 触点：`sat.rs` 选轴后、`clip` 前；需要 B 的参考面矩形（`select_ref_face` 已有）。
- 优点：只在**角点特征**触发，密堆（面-面）不受影响 ⇒ 换代面小得多。
- 风险：法线不再与任何 SAT 轴一致 ⇒ `AxisSrc` 语义要扩一个 `Corner`，`clip` 的参考面选择要能接它。

### C3 · 边-边优先（把角点当棱接触）
在 9 条棱叉积轴里，若某条轴与「两体最近特征」一致（杆的棱 × 柱的棱），即使它的 `sep` 不是最大，
也优先取它。

- 触点：`sat.rs` 选轴 + `polytope` 的最近特征查询。
- 风险：棱叉积轴在近平行时数值退化（长度² < 0.5 已被跳过），需要额外的退化保护。

**推荐顺序：C2 → C1 → C3**（C2 换代面最小、语义最干净；C1 最省事但影响面最大；C3 最容易数值退化）。

## 3. 判据（预注册，缺一不可）

在 `tests/ccd_rotational_sweep.rs`（2 m 细杆 ω=40 × 4 cm 小柱，240 tick，`substeps=1`）上：

| 指标 | 现状 | 通过线 | 说明 |
|---|---|---|---|
| `min\|φ\|`（刀锋到柱角的最小夹角） | 3.364° | **< 3.274°**（柱面） | 低于柱面 ⇒ 刀锋真的被角点挡住，而不是滑过 |
| 杆心最大漂移 | 0.711 m | **≤ 1.0 m** | 不能被甩飞（历史反例：点冲量 18 m） |
| 末态 `\|ω\|` | 10.13 | **≤ 100**（且应下降） | 转动被吸收的方向 |
| 峰值埋深 | 0.00000 | **≤ skin（0.02）** | 不得用"埋进去"换"卡住" |

**并且**（回归面，任一红即不落）：
- `m0_gates` 门槛档 `max_wake_flips < 1.0/s`、`verdict PASS`；
- 三哈希换代必须**逐条登记**（`determinism` / `m0_gates` 压力档 / `m3_collapse`），并按 ADR-0004 重冻；
- 金样：`col45` 横向 ≤ 0.01、`pile5` ≤ 0.01、`tower25` 横向 ≤ 0.05 且超 slop 点数 = 0；
- `simd_matches_scalar_bitwise` 与 `gpu_narrow_probe` / `gpu_band_probe` 必须仍绿（CPU/GPU 同口径）。

## 4. 止损（预注册，先写死）

任一条成立就**回退，不留开关**：

1. `min|φ|` 没有降到 3.274° 以下（说明这条规则根本改不到该接触的特征）；
2. 杆心漂移 > 1.0 m（说明把"擦"变成了"撞飞"，与历史点冲量反例同类）；
3. 密堆压力档最大深度比现状深 > 20%（拿稳定性换一个演示场景，不值）；
4. 需要给 `sat()` 传速度/时间才能成立（那就不属于窄相，改走求解器侧，另立项）。

## 5. 分片（落地顺序）

- **K1**：只加 `PhysConfig::corner_band`（默认 0）与标量路径的 C1 实现，跑 A/B 拿曲线；
  默认档逐位不变（`determinism` 不动）⇒ 这一步可以无条件合并。
- **K2**：按 K1 曲线决定 C2 是否值得做；C2 要扩 `AxisSrc::Corner`，同时改 `clip` 的参考面规则。
- **K3**：CPU/GPU 同口径（`narrow.wgsl` 与 CPU 对齐），跑两条 GPU 探针。
- **K4**：换代账 + 金样重冻 + `gate_all.sh`。

## 6. 边界（现在就能说死的）

- 这条路线**不改变**「掠擦接触没有法向载荷」这个事实；它改的是**接触法线的方向**，
  让角点处产生法向载荷。若 C1/C2 都没让 `min|φ|` 掉到 3.274° 以下，说明该场景的几何根本不是
  "角点接触"，而是"面-面近平行滑移"⇒ 本路线止损，P18 保持模型边界。
