# CPU 布料第四片：粒子与刚体代理接触

## 接口与域顺序

- `ClothSheet::step()` 仍保持原 provider-only 接口；`step_with_bodies()` 接收与绳索同型的 `RigidProxy` 切片。空代理列表直接走旧的布料积分/静态 provider 投影路径。
- `World` 在刚体子步、流体、绳索之后更新代理快照，再按布片注册顺序步进。每张布的反作用立即写回动态球的位置及线速度，并同步更新代理供下一张布使用。冲量影响刚体本 tick 的末态、下一 tick 的刚体积分；不会追溯重算已完成的刚体窄相。
- 粒子按数组顺序、代理按体索引顺序查询已有 `shape_penetration`。支持静态 Sphere/Box/Capsule；动态仅 Sphere。Provider/HeightField 仍走原提供者通道。钉扎粒子跳过。

## 接触口径

- 穿透距离按粒子半径计，逆质量分担几何分离；位置修正直接回填动态球。接近速度的法向分量决定冲量上限，布片速度与球体线速度施加等量反向动量变化；剩余几何纠正同步移动粒子的上一位置，因此静止初始重叠不会凭空获得速度。静态体不接收反作用，沿用完整位置投影。
- 本片只做离散的**顶点球**接触：不保证三角面内部连续碰撞/防穿越，不做摩擦、角冲量、旋转感知、动态盒/胶囊、自碰撞或布与布碰撞。强冲击可能跳过薄面；双向接触不是完整刚体-布料统一求解器。
- `body_dv`/`body_dx` 是每次调用重置的代理索引数组，分别表示刚体线速度增量及位置纠正。`World::state_hash()` 仍只覆盖刚体，布片末态需单独核对。

## 回归与后续

- 软体单测守住静态球/盒/胶囊、钉扎顶点、动态球质量分担与动量、静止重叠零冲量，以及显式跳过动态盒。
- 门面单测验证静态盒不移动、动态球同步回填位置和速度、后一张布读取先前的球位置修正；单球场景冻结 `(cloth_y, sphere_y, cloth_vy, sphere_vy)` 的 `f32::to_bits()` 四元组 `(1026684572, 3191130631, 1056986818, 1056986819)`，两次构造逐位一致。旧布料、风场、绳索及刚体冻结基线仍由现有测试守护。
- 下一阶段应在代理中引入角速度与逆惯量、统一点接触的有效质量和角冲量，并基于布片三角面做连续/面内接触，之后再开放动态非球体及处理较大时间步的防穿透问题。
