##### 8.4.22 ⭐ 残余漂移的**标度**量出来了：不是"常量冲量偏置"，是**摩擦模型的轻载阈值**

**测量**（3 维；`x` 在 t=300/900/1800 的读数；判 ∝t²/m 看 1800/300 ≈ 36×、判 ∝t 看 ≈ 6×）：

| μ | 0.25 kg | 0.5 kg | 1 kg | 2 kg | 6 kg |
|---|---|---|---|---|---|
| **0**（无摩擦） | −0.059 | −0.244 | +0.028 | −0.031 | **0.000** |
| **0.5** | **+41.1 / +133.3 / +271.5（比值 3.2×、6.6× ⇒ ≈∝t）逃逸** | +0.098 | −0.011 | +0.004 | +0.003 |

**⇒ 两条结论**：
1. **`μ = 0` 时不是漂移，是"有界的摇摆"**：读数**变号**（−0.059 / −0.244 / +0.028 / −0.031 / 0.000）
   且随质量趋零 ⇒ 它没有固定方向 ⇒ **不存在"残余常量冲量偏置"**（§8.4.21 里那条推断要收回）。
2. **唯一系统性漂移是"轻盒 + 有摩擦"**：0.25 kg 时 `x` **≈ ∝ t**（3.2× / 6.6×）⇒ 是**恒定横向速度**
   （≈0.15 m/s）在"巡航"，而 ≥0.5 kg 全部有界（≤0.1 m）。

**⇒ 机制（能解释质量阈值）**：摩擦是**位置口径库仑锥** —— 每颗每子步能扣掉的切向位移
`budget = μ · depth`。而 `depth` 是**静载穿透**，它 ∝ 重量 ∝ m；同时**每子步的切向滑移 ≈ `v_t·h`
与质量无关** ⇒ `budget / slip ∝ m` ⇒ **质量低于阈值时锥扣不住滑移 ⇒ 转成滑动（动摩擦）⇒ 巡航**。
换言之：现在的锥是 **mass-blind** 的（把"法向修正量"直接当库仑上限），而库仑锥本该是
`|J_t| ≤ μ·J_n`——两者在**两体质量不同**时要经逆质量换算才对得上。

**⇒ 下一刀（候选，未实施）**：把切向预算从"位置量"改成**与法向冲量同口径**（等价说法：把
`Δd_t ≤ μ·Δd_n` 换成 `Δv_t ≤ μ·Δv_n`，即用**同一子步实际施加的法向速度变化**当锥半径）。
**判据现成**：`rope_minimal` 的摩擦阈值（15°/μ=0.5 必须**粘住**、35° 必须滑）、
本节的漂移表（0.25 kg 必须不再巡航、≥0.5 kg 不许变差）、以及 §8.4.20 的两条"托住"判据。
⚠️ 动它之前先确认 §8.4.20 三条使能条件与这两条判据的历史读数（改口径会重冻 `rope_minimal` 的阈值读数）。

##### 8.4.23 ⭐⭐ 把两个残余**分开了**：**顺序 GS 的偏差**（可修）＋**轻载摩擦regime**（另一件事）

**决定性的判别实验**：把 `project_body_contacts` 的**粒子循环反向**（`(0..n).rev()`），其余一字不动。
若残余来自"顺序 Gauss-Seidel 的先后偏差"，读数应当**随顺序变号**；若不变，则另有其因。

| 用例 | 正向（§8.4.22） | **反向** |
|---|---|---|
| μ0.5 / 0.25 kg | +41.1 / +133.3 / **+271.5（逃逸）** | +17.0 / +99.4 / **+223.0（逃逸）** |
| μ0.5 / 0.5 kg | +0.081 / +0.072 / +0.098 | **−0.043 / −0.051 / −0.124** |
| μ0.5 / 1 kg | +0.019 / −0.013 / −0.011 | −0.013 / −0.008 / −0.006 |
| μ0 / 0.5 kg | +0.033 / −0.114 / −0.244 | −0.018 / −0.085 / −0.005 |
| μ0 / 1 kg | −0.010 / −0.023 / +0.028 | **−0.118** / +0.014 / −0.045 |

**⇒ 两句结论（这是本轮真正的收获）**：
1. **常规载重下的残余漂移 ⇒ 就是顺序偏差**：读数**随循环方向变号**（0.5 kg：`+0.098 → −0.124`；
   1 kg μ0：`+0.028 → −0.045`）⇒ 它是"按粒子索引顺序、`body_dv` 就地推进"造成的**不对称**，
   是**可修**的（对称化：两只"肩"的修正成对处理，或用两遍 Jacobi 式收一遍再落）。
2. **0.25 kg 那种"巡航逃逸"不是顺序问题**：反向照旧逃逸（223 m vs 272 m，同量级）⇒ 它与顺序无关，
   是 §8.4.22 说的**轻载摩擦 regime**（`budget = μ·depth` 里 `depth ∝ 重量`、而每子步滑移与质量无关）。

**⇒ 两条下一刀（各自独立，别混成一刀）**：
- **A. 顺序对称化**（修常规载重的残余）：判据 = 上表那些读数**变小且不再随顺序变号**；
  同时 `rope_minimal` 的摩擦阈值（15° 粘住 / 35° 滑动）与 §8.4.20 两条托住判据**不许变差**。
- **B. 摩擦锥的质量口径**（修轻载 regime）：把 `Δd_t ≤ μ·Δd_n` 换成与**法向冲量同口径**
  （`Δv_t ≤ μ·Δv_n`）。这条会**动摩擦语义** ⇒ 预期重冻阈值读数，先量后改。
⚠️ 两条都**不许动 §8.4.20 的三条使能条件**。

**探针配方（跑完已删）**：`crates/vxl-phys-soft/tests/drift_reversed_probe.rs`（同 §8.4.22 的表，
但循环反向；反向本身是一行 `(0..n).rev()`，跑完已 `git checkout` 还原）。

##### 8.4.24 ✅ A 落地：**施加顺序改成几何的函数** ⇒ 数组方向不再影响结果（6/6 逐位相同）

对"绳沿 `x` 铺开、索引即左→右"的常规场景，它与**原来的数组顺序逐位等价** ⇒ 既有读数全不动，

##### 8.4.25 ✅✅ B 成了：库仑锥取**冲量口径** `μ·w_p·λ` ⇒ **轻载 regime 修好**（0.25 kg 从巡航逃逸变托住）

**那一刀（一行）**：`apply_body_hit` 里摩擦的位置预算 `budget = friction * depth` →
**`budget = friction * (w_p * lam)`**。理由：库仑锥本是 `|J_t| ≤ μ·J_n`，而本接触**实际**施加的法向冲量
∝ `λ`（`J_n = m_p·w_p·λ/h`），**不是**几何穿透量 `depth`（后者只在几何支被选中时与 λ 同口径；
静载下 λ 被速度钳位到远小于 `λ_geom`）⇒ 原来的 `μ·depth` 是**偏大**的预算。

**⚠️ 我事先的预测是错的**（留档）：我以为"预算变小 ⇒ 轻载更糟"，实测**相反**。⇒ 新的机制读法：
**偏大的预算不是"承重"，而是棘轮源**——过强的切向扣除把粒子/盒子每子步越推越偏，方向一致 ⇒
3 维下攒成巡航。这与 §8.4.23 的两条读数完全吻合（`μ=0` 时只是**有界摇摆**、一有摩擦就**巡航**）。

**读数（3 维、1800 tick）**：

|---|---|---|
| μ0.5 / **0.25 kg** | **+41.11 / +133.27 / +271.51（巡航逃逸，末 y −4241.9）** | **+0.0030 / +0.0095 / −0.0153（托住，末 y +1.002）** |

**无一处冻结量被动**（逐项复核）：`rope_scene` 静态盒冻结哈希 **`5a2440914067fe15` 未动**、

##### 8.4.27 ✅ 睡眠体对软体域**呈现为静态**（一行）⇒ 绳不再打扰睡眠体（含**金丝雀验证**）

**病灶（实测，2026-09-28）**：`rope_pass` 建代理时不管 `awake` ⇒ 绳的一切反作用都落在睡眠体上。
**不只速度**：金丝雀跑（临时撤守卫）显示睡眠体 `|v|` 涨到 **0.48 m/s**，**位置还被推了 12 cm**
（0.2499 → 0.1308）—— 因为**位置口径那一腿 `body_dx` 是直接写在 `bodies.position` 上的**，不走积分
⇒ "睡眠"挡不住它。醒来（或本就该静止的体）就被弹出/移位。

**那一刀（一行）**：
```rust
inv_mass: if self.bodies.is_dynamic(i) && self.bodies.awake[i] { self.bodies.inv_mass[i] } else { 0.0 }
```
⇒ 睡眠体对绳索**呈现为静态**：接触照做（盒仍是几何、可感），而门面既有的"静态体不收反作用"那条
**自动跳过两腿回填**（`body_dv` 与 `body_dx` 都在那个 `inv_mass <= 0` 的 `continue` 之后）✓
这与 2b 流体的口径一致（那边睡眠体照样生成边界粒子、但 `fluid_reaction_pass` 判 `awake` 才施力）。

**判据（在树，且验过金丝雀）**：`crates/vxl-phys/tests/rope_scene.rs::rope_does_not_disturb_a_sleeping_body`
—— 盒在网格地形上睡稳（断言 `!awake`）后把绳搭在**盒顶**（绳最低粒子 0.5016 vs 盒顶 0.4999 ⇒ 接触确实建立），
900 tick 后断言：**不被吵醒** + `|v| < 1e-3`（实测 `0.000e0`）+ 位置不动。
**金丝雀**：撤守卫后同一条判据变红（`|v| = 4.8e-1`、位置 −12 cm）⇒ 它确实在测这件事。

**对既有判据无影响**（逐项复核）：绳的三条"托住"判据里盒**从不入睡**（1800 tick 睡眠 0 次，实测），
静态盒 `inv_mass` 本就是 0 ⇒ 本行对它们恒等；`rope_scene` 冻结哈希 `5a2440914067fe15`、悬垂
`faf4d9e7443ddbef`、静态就位 `36eaadb902cc8481`、摩擦阈值、金样门**全未动**。

##### 8.4.28 ✅ 角冲量注入的**契约**钉住了（2× 口径缺陷：从"记录的隐患"变成"被判据守住的规格"）

**缺陷（记录在 §8.4.10 的那条）**：`force`/`torque` 是**每子步消费并清零**的累加器，
而门面的角反作用注入发生在**所有子步之后** ⇒ 只被**一个**子步消费 ⇒ 实收角冲量 = `τ/substeps`
（默认 2 ⇒ **差 2×**）。流体那条是**每子步**注入（同段位），绳索这条漏了。

**本轮的处置**：这条注入**当前停用**（接触模型看不见转动，§8.4.10）⇒ 口径错误**不影响任何可观测行为**，

##### 8.4.31 ✅ 2c-3 落地（**默认关闭的开关 + 实测登记**）：角反作用可用、符号对、托住不崩
