## 1. 惯性：不是一个布尔值

### 1.1 现在有什么【本仓】

- **解析惯量**：盒/球/圆柱/胶囊/锥都是解析式，逐形状给 `local_inv_inertia: Vec3`（体坐标系**对角**）
  —— `crates/vxl-phys-core/src/mass.rs:9-11,15`。
- **世界系变换**：`world_inv_inertia(q, d)` = `R·diag(d)·Rᵀ`（`core/math.rs:319`），
  求解器每帧预积成 `Mat3` 复用；施加冲量走 `apply_world_inv_inertia`（`core/body.rs:172-175`）。
- **复合体**：按子形状求和 + 平行轴，**精确并集**（不是并集 AABB 盒近似），判据
  `crates/vxl-phys/tests/compound_mass.rs`（哑铃质心惯性关系 `inv.x > inv.y`）。

### 1.2 三处有意的近似【本仓】

1. ✅ **陀螺项已接上（2026-10-14）**：原来速度积分只有 `ω += I⁻¹_world·τ·dt`、**没有** `ω × (Iω)`
   ⇒ 无接触自由旋转的非球体**不守恒角动量**、也不复现极迹摆动（网球拍定理 / Dzhanibekov）。
   现在实现落在**新文件** `crates/vxl-phys-integrate/src/gyro.rs`（`lib.rs` 受 god 门双棘轮 ⇒
   调用点只留一行 `gyro::integrate_angular(...)`）：**陀螺项 + 隐式中点**（固定点迭代 3 遍）+
   **三条早退**（各向同性惯量 / 退化惯量 / **自由进动率快过 `dt` 能分辨的尺度**）。
   **读数**（`examples/free_rotation_probe.rs`，1200 步、无重力无接触）：

   | 用例 | 修前 `max\|ΔL\|/\|L\|` | 修后 | 解析对拍 |
   |---|---|---|---|
   | 不对称盒 2×1×0.5（非主轴 ω = 6） | 0.622 | **0.0232**（KE 漂 5e-6） | 极迹摆动 `ω₃` 摆 ±4.46 |
   | 对称陀螺（方盒 1×1×0.5，ω = (1,0,6)） | 0.123、进动率 **0.000** | 0.0031 | 进动率 **3.600** vs `ω₃(I₃−I₁)/I₁` = **3.6** ✓ |
   | 细杆自旋**偏离主轴**（`ω·dt·(I_⊥/I_∥−1) ≈ 4·10²`） | 0.199 | 0.199（**已知缺口**：解不动档） | — |

   ⚠️ 三条实测教训：① **动能读数抓不到这个缺口**（`ω` 恒定 ⇒ KE 也恒定，两档漂移都 ~1e-6）——
   判据必须落在 **L 矢量**上（首版探针只量 `|L|` 的模长，读数全 0，踩过）；② **显式格式被否证**：
   显式 `ω += dt·f(ω)` 对不对称盒**发散**（动能 +323%、`ω₃` 摆到 ±9）、对称陀螺 +13% ⇒ 必须隐式中点；
   ③ **极各向异性（细杆/薄板）+ 偏离主轴** 一档无论显式还是隐式都解不动（进动率 ≫ 1/dt）⇒
   按"可分辨性"**退回旧式并如实登记**（`tests/ccd_energy.rs` ③ 的自旋细杆顶墙读数因此**保持
   ×1.092 不变**，不引入回归）。判据 `crates/vxl-phys/tests/free_rotation.rs`（4 条：守恒 / 解析进动 /
   各向同性逐位不变金丝雀 / 细杆缺口金丝雀）。**换代账（ADR-0004）**：`determinism`
   `0x655cdbf4… → 0x8c5c8fc9…`；`m0_gates` 两档与 `m3_collapse` **逐位未变**（体是立方体 ⇒ 走早退）。
2. **复合体丢离对角**：`src/props.rs:9-14` 明写"旋转项只取对角、**离对角项被丢弃**（对称/轴对齐
   的复合体本来就为零）"。⇒ 主轴与体轴不对齐的复合体（斜装的板 + 球）转动惯量偏。
3. **平行轴按原点、不按真质心**：同处注明"本仓无质心偏移字段" ⇒ 偏心复合体的力矩效应不建模
   （与锥同款，`mass.rs:100` 也是这个口径）。

### 1.3 什么时候看得出来

接触主导的场景（堆叠、静置、滚动）几乎无感；**自由飞行 + 高速自旋**才显形：投掷物、陀螺、
卫星、被炸飞的碎片（M3 破坏域恰好会产生大量这种体）。第 3 条还会让"偏心复合体当摆用"错。

### 1.5 判据建议（✅ ①②④ 已立门 2026-10-14，见 `crates/vxl-phys/tests/free_rotation.rs`）

1. ✅ **自由旋转守恒**（无接触、无非保守力）：`L` 矢量与动能 `½ωᵀIω` 在 1200 步内相对漂移
   ≤ 给定上界（**实测**：修前 `|ΔL|/|L|` 0.622/0.123、修后 0.023/0.0031；⚠️ **必须看 L 矢量**，
   只看 `|L|` 的模长在"绕固定轴转"下恰好不变 ⇒ 读数全 0）。
2. ✅ **对称陀螺解析对拍**：`I₁=I₂≠I₃` 的欧拉陀螺有闭式解（进动率 `ω₃(I₃−I₁)/I₁`）
   ⇒ 实测 **3.600 vs 3.6**（修前 0.000）✓。
3. **复合体主轴**：把"斜装板"的惯量对角化后与解析主轴值比（现在必然对不上 —— 这条会先红，
   红得有价值）。
4. ✅ **金丝雀（口径已修正）**：**各向同性惯量**（球/立方体）⇒ `ω × (Iω) ≡ 0` ⇒ **逐位不变**。
   ⚠️ 原文写的"`ω ≡ 0` 或 `τ ≡ 0` 时逐位不变"**过强**：`τ ≡ 0` 正是自由旋转那一档（必须变）；
   而"`ω ≡ 0` 但 `τ ≠ 0`"在**隐式**格式下也会变（中点处的 `ω ≠ 0` ⇒ 陀螺项非 0）—— 稳定性要求
   与"这一档逐位不变"不可兼得（显式才不会变，但显式发散）。现行口径只保**各向同性**那一条。

## 2. "不断更换位置"与电梯难题：三条断链

### 2.1 现在的语义【本仓】

`BodyType` 只有 `Static` / `Dynamic`（`crates/vxl-phys-core/src/body.rs:20-22`）。宿主要让一个体
"按给定运动走"，只能二选一：

- **改位置**（静态体）：合法但**没有任何配套语义**（见 2.3–2.5，含实测）；
- **给速度**（动态体）：会被重力、接触、限速改写，不能当"运动学"用。

`SPEC.md:323,372` 把"运动学体"记在 **M2**（与"传送带各向异性方向""动-动 CCD"同批）——
也就是说这是**已知要做的**，本文的价值是把它的真实代价提前钉住。

### 2.2 实测读数（探针已入库）

**修复前**探针（本机 2026-10-12，`--test-threads=1`，睡眠关闭；长度 m、速度 m/s；该文件已在
PR #244 里改写成 `kinematic_contracts.rs` —— 同一批场景、钉的是**修复后**的行为）：
①–⑤ 是本节这张表，⑥⑦（睡熟的堆 × 上行支撑、动态支撑焊接岛）在
[`SURVEY-EXTREMES-AND-BORROW.md`](SURVEY-EXTREMES-AND-BORROW.md) §1（极端工况视角）。

| 场景（1 s 驱动） | 正确行为 | **实测** | 判读 |
|---|---|---|---|
| ① 传送带：静态地板沿 +x 0.6 m/s | 盒 `Δx ≈ 0.51`、`vx ≈ 0.6` | **`Δx = 0.0066`、`vx = 0.0075`**（接触还在） | 完全不携带 —— 切向没有"去穿透"可借，缺口最纯 |
| ② 电梯：静态地板沿 +y 0.6 m/s | 相对位移 ≈ 0、`vy ≈ 0.6` | **相对 `−0.1377`、`vy = −0.9509`、末态接触 0** | 被去穿透顶了一小段就**掉队**，最后在**自由下落**（不是"被托着"） |

⑤ 是这条线最要紧的一格：`update_proxies` 只对 `is_dynamic(i) && awake[i]` 调
`move_proxy_scaled`（`crates/vxl-phys-broad/src/bvh_phase.rs:192-210`），而 `update_aabbs`
对静态/睡眠体 `continue`（`:173-175`）、`full` 只在体数变化/首帧为真（`:428-438`）
—— 同一条"位置不变"假设的两个半边。⇒ **"把静态体当电梯/传送带/可瞬移地形用"不是功能缺失，
是静默失效**；④′ 那格还排除掉了一个看起来可行的临时补丁。

### 2.3 断链 ①：接触把静态侧速度**恒按 0**

```rust
// crates/vxl-phys-solver/src/helpers.rs:92-99
pub(crate) fn group_vel(lv, av, local_of, i, r) -> Vec3 {
    let k = local_of[i];
    if k == u32::MAX { Vec3::ZERO }        // ← 静态侧：速度恒为精确 0
    else { lv[q] + av[q].cross(r) }
}
```

岛内缓冲只 gather **清醒动体**（`solver_impl.rs:284-296`），静态侧用 `u32::MAX` 代表，
`group_apply` 对它直接 `return`（`helpers.rs:106-115`）。⇒ 摩擦/法向求解看到的是"对面不动"，
于是：**站在被搬着走的平台上不会被带走，皮带上不会被输送**。注释里的理由（"静止体速度恒为
精确 0"）在"静态体不会被挪"的前提下是自洽的 —— 那正是要打破的前提。

### 2.4 断链 ②：宽相**从不移动静态体的树代理盒**

```rust
// crates/vxl-phys-broad/src/bvh_phase.rs:173-175
if !full && (!bodies_ref.is_dynamic(i) || !bodies_ref.awake[i]) {
    continue; // 睡眠/静态：位置未变，沿用上帧 AABB。
}
```

`update_proxies` 也只处理 `is_dynamic(i) && awake[i]`（`:192-210`），而 `full = leaves_missing`
只在**首帧/体数变化**时为真（`:428-438`，树链化超限的重建**复用现有 AABB**）。
⇒ 把静态体挪走之后，树里仍是旧位置的代理盒；精确 AABB 也是旧的。**实测**（§2.2 的 ④/④′/⑤）：
瞬移到落点下方的地板接不住东西（盒穿到地下 14.7 m），而且**体数变化触发的全量 AABB 重算
也救不回来**（④′）—— 只有"动态 + 清醒"的体才会被 `move_proxy_scaled` 挪代理（⑤）。
这是**静默的**：不报错、不警告；慢速小幅移动还会"看起来能用"——① 里接触（数 = 1）
在平台横移 0.6 m 之后**依然有效**，因为动体侧的查询命中的正是**陈旧代理**覆盖的那片区域。

### 2.5 断链 ③：没有"位移驱动"这一档，也没有"挪动即唤醒"

- 没有 `next_position` / `set_kinematic_target` 这类入口（`world_body.rs` 的公开面里没有挪体 API），
  宿主只能直接写 `world.bodies.position[i]`；速度**不会**被反算 ⇒ 即便 2.3 修好，
  位移驱动的平台速度也是 0。
- 挪动不唤醒邻域、不重置睡眠计时、不清暖启动锚点（未发现任何"外部位移"通道）。
  `RECYCLE_DIST = 0.01`（`solver/cfg.rs:5-8`，收窄自 Rapier 的 0.05）与 ADR 0003/0007 的
  "特征 id + 1×skin 近邻回退"都是按"接触面位置基本不变"设计的；`OPEN-PROBLEMS.md:731`
  已经讲清"滑动接触的锚点分离**就是**真实相对运动"，但"**支撑在动**"这一档还没定义。

### 2.6 已经做对的一半：CCD 走的是相对运动【本仓】

2026-10-11 修的两处（`ROUTE.md:405-413`）已经把"移动的墙"纳入：目标位置**随采样时刻推进**、
命中用**相对速度**判决、响应是**按质量分摊的非弹性相对停**，且只算"沿法向正在接近"的采样
（贴地滑行不锁死）。⇒ "高速撞上移动平台"这条**已经通了**；缺的是"低速持续接触"这条
（也就是 2.3–2.5）。

### 2.7 外部件（本机可复核）

Rapier 0.35.3（本仓金样对拍包 `gold-sample/Cargo.toml` 直接依赖）【源码】：

- 两种运动学体：`RigidBodyType::KinematicPositionBased` / `KinematicVelocityBased`
  （`.../rapier3d-0.35.3/src/dynamics/rigid_body_components.rs:46,55`），
  且 `is_dynamic_or_kinematic() = body_type != Fixed`（`:81-83`）。
- **运动学体进求解体**：求解器对"动或运动学且未睡"的体取质量属性
  （`.../src/dynamics/solver/solver_body.rs:112-116`）⇒ 相对速度里带上平台速度，
  **摩擦自然把人带走**、传送带自然成立。这正是 2.2 的修法。
- 管道里对 `KinematicPositionBased` 单独分支（`.../src/pipeline/physics_pipeline/substep.rs:257`）。

Box2D / Jolt / PhysX / Unity 的"运动学体 + 无限质量 + 给定速度"是同一族做法（【推断】，
本文未逐个复核其源码）。

### 2.8 方案（三件套 + 两处配套）与判据

**K1 体类型**：`BodyType::Kinematic`（`inv_mass = 0`、不施力、但**速度是输入**）。
两档驱动：**速度驱动**（宿主给 `v/ω`，位置由积分推进）与**位移驱动**（宿主给目标位姿，
`v = (x_next − x)/dt` 反算）。位移驱动必须由引擎反算速度，否则 2.3 修了也白修。
**K2 接触**：把"静态侧恒 0"改成"**按体读速度**"（运动学体作为岛外伙伴登记 `lv/av`）。
**K3 宽相/睡眠/锚点**：运动学体走"清醒动体"分支（AABB + 代理 + 查询）；挪动/位移驱动要
**唤醒接触邻域并清锚点**。
**K4 传送带** = 摩擦的**切向目标速度**（与 `SPEC §4.4` 各向异性方向应用落在同一处）。
**K5 非惯性系**（"就在电梯里模拟"）：局部参考系里的伪力（离心 / 科里奥利 / 欧拉），
只对该子世界加 —— 这条与 K1–K4 是**两回事**，别混（前者是"世界里有个电梯"，后者是"电梯里有个世界"）。

判据（全部可测）：

1. **电梯**：平台以 `a` 上行、载荷静摩擦系数 μ ⇒ `a ≤ μg` 时相对位移 < 1 mm/1 s 且不穿；
   `a > μg` 时滑移速率与 `a − μg` 的解析值对拍。
2. **传送带**：belt 目标速度 3 m/s、μ=0.7 ⇒ 盒稳态速度 ≈ 3 m/s（±2%）、稳态
   `|v_rel| < 1e-3`、无丢包（末态位姿单调前进）。
3. **瞬移/换位**：挪体后**下一 tick** 宽相结果与暴力 O(n²) 逐位一致（现在会漏对）；
   把支撑挪走时上方载荷必须醒；暖启动冲量峰值 ≤ 解析接触冲量上界（挪动不许产生"补课冲量"）。
4. **相对系不变性**（金丝雀）：整场随平台一起平移/旋转 ⇒ 相对坐标与相对速度逐位一致。
5. **不退化**：R1–R10 基线与金样哈希的换代窗口里，位移量为零的档必须逐位不变。

代价：改接触速度语义 = **换代**（哈希变）⇒ 需要一次显式的换代窗口，不能混进纯重构。

### 3.3 大坐标精度（可算的事实）

f32 尾数 24 位 ⇒ 在 `≈1e5 m` 处，1 ulp = `2^(17−24)` = **7.8 mm**，与默认皮肤带
`contact_skin = 0.02 m`（`core/config.rs:217`）是**同一量级**（约 39%）。⇒ 世界半径到 10 万米时，
"分离距离"本身已经落进量化误差。两条对策：

- **floating origin**（按相机/主角周期性重定原点）：改动面在中上层，不碰求解核心；
- **双精度位置**：与现行纪律冲突 —— `f64-gate` 是**硬判**（"求解核心禁用 f64"，
  `scripts/f64_gate.py` 头注：严格 f32 是跨平台哈希 bit 级一致的前提）⇒ 走这条路要先改门，
  代价远大于 floating origin。

判据建议：**平移不变性**（把整场平移 `1e4 m` 后与原地跑同一场景，比较**相对**量：接触数、
末态相对位姿、R1–R10 各项）—— 不平移友好时这条会立刻显形。

## 4. 黏性（黏稠）

### 4.1 现状【本仓】

- **流体**：Monaghan 人工黏度 `α = 1.0`（`Π = α·c·μ/ρ̄`，**只作用于接近对**，`fluid_force.rs:192`）
  + XSPH 速度平滑 `ε = 0.1`（对称式、逐对动量守恒、**只耗散**，`fluid/config.rs:18,59`）。
- **口径诚实**：`fluid_medium.rs` 的 `viscosity` 报 **`FluidConfig::dynamic_viscosity`**（Pa·s，默认 0）
  —— 它是**物理材料参数**，与 XSPH 的 `ε`（无量纲数值器件）分开：**不编造 ε → Pa·s 的换算常数**。
  ⇒ 液体**内部**的耗散仍只有 α/ε 两个数值旋钮（"物理黏度没有桥"只解决了一半，见 4.2①）。
- **喷溅域**：`splat/viscosity.rs`（`SelfViscosity`，ε=0.1，照抄液体侧对称 XSPH 形式，
  逐对 `m·dv` 反对称 ⇒ 动量守恒；等速度金丝雀）。
- **刚体侧**：二次风阻（`field::WindField`，`k·|v_rel|·v_rel`）、面元气动（`vxl-phys-aero`）、
  浮力采样；接触是**软接触正则化**（`contact_freq_hz` / `contact_damping_ratio` /
  `static_contact_freq_hz`，`core/config.rs:136-150`）。**没有**全局线性/角阻尼字段。
  **2026-10-14 加**：介质（流体）给了 `dynamic_viscosity > 0` 时，刚体在介质里吃
  **Stokes 线性阻力** `F = −6πμ·r_eq·frac_sub·v_rel/(1 + dt/τ)` + **转动阻力矩**
  `T = −8πμ·r_eq³·ω/(...)`（`world_step/viscous.rs`；`r_eq` = 体积等效球半径 ⇒ 球**精确**）；
  默认 0 ⇒ 整段不进（四道哈希逐位未变）。

### 4.2 缺口

1. **Pa·s 口径**（**部分解决**）：刚体侧的介质参数已经是 Pa·s（`FluidConfig::dynamic_viscosity`），
   但**液体内部**的耗散仍只有 α/ε —— 还没有把 μ 标定进 SPH 的黏性项（Peer 2015 的隐式黏度是
   正路）⇒ 调 α/ε 仍不可迁移、仍不能按"水的黏度"设定液体自身。
2. **高黏/稠密介质里的刚体**（**部分解决**）：**Stokes 线性阻力 + 转动阻力矩已落地**（见 4.1）；
   仍缺 **附加质量**（added mass，需要介质加速度估计）、**历史力**（Basset，需要记忆核）
   ⇒ "启停"瞬态里那两项还不在了；另：τ ≲ dt 的极黏档（沥青）需要半解析积分才能给准终端速度
   （当前半隐式写法在那一档**饱和**，偏差 `1 + dt/τ`，见 `viscous.rs` 头注）。
3. **润滑 / 油膜接触**：法向阻尼与切向摩擦耦合在一个接触约束里，无法表达"黏着油膜"
   （需要把切向的黏性项与库仑项分开）。

### 4.3 外部件与判据

- Monaghan, *Smoothed Particle Hydrodynamics*（ARA&A 1992）—— 人工黏度与 XSPH 的原始出处
  （本仓用的就是这两个）。
- Macklin & Müller, *Position Based Fluids*（TOG 2013）—— PBF（`SPEC §4.8` 的高黏档）。
- Peer, Ihmsen, Cornelis, Teschner, *Implicit Viscosity*, 2015 —— 黏度的隐式积分（稳定 + 参数可迁移）。
- 附加质量：Causin 等 2005（分区流固耦合的附加质量不稳定性；本仓 `PLAN-COUPLING.md §7`
  已引用）【本仓】。

判据建议：① **自由衰减解析**（`v(t) = v₀e^{−λt}`）逐档对拍；② **Stokes 终端速度**
（给 Re 上界口径，低 Re 档才允许对 Stokes，否则对 Schiller–Naumann 修正）；
③ **只耗散金丝雀**（`v ≡ 0` ⇒ 逐位不变，同 `splat/viscosity.rs` 的口径）；
④ **能量耗散单调**（无外力档，总动能不增）；⑤ 档位用 **Re 数**定义而不是形容词。

**2026-10-14 落地（第一刀 = 刚体侧的 Stokes 阻力）**：

- 档位：`FluidConfig::dynamic_viscosity`（Pa·s，默认 0 = 关）。
- 律：`world_step/viscous.rs`（平动 `6πμ·r_eq·frac_sub` + 转动 `8πμ·r_eq³`；`r_eq` = 体积等效球半径）。
- 判据：`crates/vxl-phys/tests/viscous_medium_contracts.rs`（5 条）+ `viscous.rs` 的单元判据（4 条）。
  **场景口径**：介质必须**冻结**（流体自身 `gravity = 0` + 数值黏度全 0 ⇒ 实测粒子 `max|v| ≈ 1e-5`）
  —— 常规水盆里做不了定量对拍（P7：2a/2b 是**定性档**；体把水推开 ⇒ ρ 爆 ⇒ 速度上限，
  见 `RECIPES.md` "别把体直接放进已有水格"）。实测：λ = 7.05 / 7.32（解析 7.854，两窗一致 ✓）、
  转动率 2.535（解析 2.618）、旧口径（μ = 0 的二次阻力）同窗 2.204 ⇒ A/B 分离清楚。
- 换代账：**零**（默认 μ = 0 ⇒ 四道哈希逐位未变）。
- 探针：`cargo run -q --release -p vxl-phys --example viscous_medium_probe`。
- **剩**：液体内部的 α/ε → μ 标定（Peer 2015 隐式黏度）、附加质量、历史力、τ ≲ dt 的半解析积分、
  以及 ② 的**终端速度**档（要等体-液的定量耦合：P7）。

## 5. 摩擦

### 5.1 现状【本仓】

- **四档模型**：`FrictionModel::{Coulomb, StaticKinetic{μs, μk, v_crit}, Anisotropic{μ1, μ2, angle}}`
  （`core/config.rs:27,262-282`，默认 `Coulomb 0.5`）；材质对组合律 `√(μa·μb)`
  （`core/material.rs:4`，Box2D 同族）。
- **两切向 + 漂移粘着**：两条切向约束（`solver/helpers.rs:61`）配切向漂移回拉，

  `constraint.rs:306-321,363-396`）；接触回收半径 0.01 m（收窄自 Rapier 的 0.05，
  `cfg.rs:5-8`，附实测：门槛场景末态 38→7 体醒）。
- **布料侧自摩擦**：点-点 + 点-边对，同一条库仑锥、同一个 μ（`ROUTE.md` M4 行）。

### 5.2 缺口

1. ~~**各向异性方向应用**~~ ✅ **已落地（K5，2026-10-12）**：对齐基两轴独立上钳（`friction_frame`
  把 μ1 轴投到接触面当 `t1`）+ 传送带切向目标速度 `belt`；判据 `friction_anisotropy_contracts.rs`
  A1–A4。⚠️ 实测记一笔：第一版用**共享预算的椭圆锥**，四个角点"净和相消的扭转分量"会挤占主轴额度
  ⇒ 沿 μ1 的极限从 0.95 掉到 0.49；改成两轴独立上钳后 = 0.9488（解析 √0.9）。
2. ~~**滚动摩擦缺席**~~ ✅ **已落地（2026-10-13）**：`PhysConfig::roll_resistance`（米 = 等效力臂）——
   球在坡上按 `a = 5g(sinθ − μ_r·cosθ/r)/7` 减速、`μ_r > r·tanθ` 时**停住**；
   判据 `rolling_resistance_contracts.rs` R1–R4（关档 = 纯滚动解析、开档对解析、缓坡按住、不注入寄生自旋）。
   ⚠️ **扭转摩擦：有意不做**（R5 钉住）：多接触点的自转盒**已被点摩擦停住**（实测 20 → 0 rad/s，
   与 `roll_resistance` 无关 —— 四个接触点提供力臂），而**单点接触绕法向没有力臂** ⇒
   按构造不可能有扭转阻力（这正是陀螺尖能长转的原因）。⇒ 这条不是欠账，是物理边界。
3. **摩擦锥的盒近似**：两切向各上钳到 `μ·pn`，合起来是四边形而不是圆 ⇒ 斜角方向过约束
   （经典误差，量级 ~8% 于对角方向）。
4. 静摩擦对"移动支撑"的语义（= §2）。

### 5.3 外部件与判据

- Catto, *Iterative Dynamics with Temporal Coherence*（2005）—— 顺序冲量 + 暖启动的原始文献。
- Catto, GDC 2011 *Solving Constraints* / *Soft Constraints* —— 本仓 `contact_freq_hz` /

### 6.2 缺口

1. **SDF 体积-体积**：现在没有一条"两个体积量的互补关系"（谁在谁内部、深度多少、怎么顶出）
   的统一路径 —— 体素/SDF 都当**表面**用，深穿透明确不保证（`OPEN-PROBLEMS.md:2062`）。
   ⚠️ **2026-10-14 已把它量成台账**（`examples/deep_penetration_probe.rs`：四条通道 × 埋深
   0.2/0.5/1.0 m、半径 0.45）：**体素 ✅ 全档顶出**（唯一一开始就对的一族）；**盒在埋深 ≥ 半径时
   穿过实心盒** —— 根因 = `prims::sphere_convex_ab` 的"球心在凸体内"分支写 `radius + max_d`
   （`max_d ≤ 0` 是最近面的带符号距离）⇒ **越深报得越浅**、埋过半径直接报"无接触" ⇒ **已修**
   （改 `radius − max_d`：埋 1.0 m 顶出并静置在 `y = +0.4450`、KE → 0）；**凸壳 ≥ 0.5 m 法线错**
   （走 GJK/EPA 那条：报 `n = (−1,0,0)`、深度 2.85，而正确的最小平移是 1.45 ⇒ 球被横向推走）
    ⇒ **已修**（`narrow/src/hull_sphere.rs`：球心在壳内时改用**最近面**的解析口径 —— 凸壳只存点云
    ⇒ 暴力枚举面 C(n,3)·n）；**"顶出后侧滑"**（盒/壳把球从深埋顶出时塞进 `vx ≈ −2.6 m/s` + 自旋
    ⇒ 从 4 m 平台边缘滚走：埋 0.2 m 落 `y = −94`、0.5 m 落 `y = −26`）⇒ **已修**（同日第三刀）：
    根因 = 球心**恰好落在面平面外侧一个浮点噪声量**（顶出经过面平面那一 tick 的 f32 累加正好落在
    `y = 0`）时，"内/外"判据（严格 `d > 0.0`，无容差）判"外"，而 `(closest − center)` 的模只剩
    `~1e-8` ⇒ **方向是归一化噪声**（盒顶档实测 `n ≈ (−0.943, +0.106, −0.314)`）；口径与判据收进新文件
    `narrow/src/surface.rs`（退化距离档 ⇒ 与体内**同用最近面口径**，容差 = 坐标量级 `8·ε_f32`），
    壳侧另加两处：`deep_exit` 的"体内"判据加**尺寸量级**容差 + `hull_pair` 的 EPA 腿对面是**球**时
    收敛成**单点**（顶点带会把接触点放到 4 m 壳的**角**上、力臂错 2.8 m）；三档实测 0.2/0.5/1.0 m
    全部 `+0.4450`、**μ = 0** 下 `max|vx| = max|vz| = max|ω| = 0`；
    **三角网** = "薄壳无内外判定 + 平面 provider 的 AABB 零厚 ⇒ **配对都没有**"（语义限制）；
    **喷溅 SDF 场** = "密度场在材料内部**梯度反向**"（模型限制）。判据
    `crates/vxl-phys/tests/deep_penetration.rs`（5 条）+ 窄相单测（`surface.rs` / `hull_sphere.rs`）；
    后两类是**语义/模型**限制，登记 **P22**。
2. **变形体 × 变形体**：布料自碰撞是点-点 / 点-边 + 粒子半径近似（`ROUTE.md` M4），
   不是体积；两件软体互相"挤"的形状保持没有保证。
3. **流体的"体积"**是密度函数的结果，不是守恒量（R7 已经把口径讲清 —— 这是**已知**的、
   不是新缺口；列在这里是为了别把"体积守恒"当成流体已有能力）。

② SDF 体积接触的**最大穿透 ≤ skin**（每 tick 统计）；③ 布料气压 `k → ∞` 时体积收敛到 target

## 7. 穿墙（隧道效应）

### 7.1 现状【本仓】

扫掠式 CCD，**四道闸**：

1. 速度阈值 `ccd_speed_threshold`（默认 `INFINITY` = **关**，`core/config.rs:219`）；
2. 尺寸比 `ccd_extent_ratio = 0.5`；
3. 单 tick 最大扫描段数 `ccd_max_steps = 64`；
4. **采样预算自洽**：段长 ≤ 0.5×最小半长，预算不够就在**位置积分之前**限速到可行域
   （旧实现静默截段 ⇒ 3000 m/s 也穿；`ROUTE.md:405-407`）。

目标集**含运动体**（位置随采样时刻推进 + 相对速度判决 + 按质量分摊的非弹性相对停，
`ROUTE.md:408-410`）；命中只在"沿法向正在接近"时算 ⇒ 贴地滑行不被锁死
（`ccd_does_not_lock_sliding_body`）。测试：`crates/vxl-phys/tests/ccd_tunneling.rs` 4 条
（默认关的决策点 / 采样预算 / 运动目标 / 静态墙对照）。

### 7.2 缺口

1. **默认档**：`SPEC §4.12` 写的是"默认选择性"，现状默认**关**（`ROUTE.md:411-413` 把它
   如实标成"能力边界"）⇒ 默认档只靠 `max_linear_velocity = 100 m/s` 兜底。
2. **旋转扫掠**：现在扫的是**平移段**；细长体高速自旋（角速度 × 长臂的线速度远超平移速度）
   不在检内【推断】。
3. **薄壳/三角网 TOI 的稳健性**：薄壁（厚度 < 皮肤带）依赖尺寸比闸与限速，缺"薄壳专属"的判据。
4. **动-动**：相对运动那一半已经做了，但 `SPEC.md:323` 仍把"动-动 CCD"记在 M2 ⇒ 口径要对齐
   （要么更新 SPEC 的余项，要么补另一半）。
5. **能量账**：CCD 的响应是**非弹性相对停** ⇒ "CCD 不该吃掉超过解析界的动能"这条判据还没立。

### 7.3 外部件与判据

- Mirtich, *Impulse-based Dynamic Simulation of Rigid Body Systems*（博士论文 1996）
  —— conservative advancement（本仓扫掠的思想源头）。
- **Speculative contacts**：`SPEC §4.3` 的四档皮肤带（0.02/0.01/0.005/0.002）就是这一族的
  "保持距离"参数（本仓已用，见 `core/config.rs:217` 的注：与 Rapier 预测距离 0.02 对齐）【本仓】。
- Rapier 的 CCD 是**两段式**：`find_first_impact` + `solve_continuous`
  （`~/.cargo/registry/src/index.crates.io-*/rapier3d-0.35.3/src/dynamics/ccd/ccd_solver.rs:98,158`；
  `sweeps.rs`）【源码】—— 本机可对拍"同一场景 TOI 是否一致"。

判据建议：① 1000 m/s 撞薄墙不穿（已有 4 条当种子）+ **旋转细杆**档（ω×r 主导）；
② 开/关 CCD 的末态动能差 ≤ 解析界；③ 默认档改成"选择性"后的换代判据
（"默认档下 10⁴ m/s 也不穿，且 R1–R10 与金样只在允许的窗口内变"）。
