# 天气线任务单（极端天气 · 恶劣天气）

> 定位：在现有域（刚体 / 体素破坏 / 软体布 / 流体 / 气动 / 海洋）之上，做**可判定的恶劣天气**，
> 不是做大气科学模拟。每条任务都带**判据**与**金样**，默认档不受影响（与现有 opt-in 纪律一致）。

## 0. 硬约束（先写死，免得后面吵）

1. **纯 Rust**：物理核心与门脚本之外不引入 Python 依赖（门脚本属既有例外）。
2. **确定性**：每条新特性必须**默认关**；开时金样用**有界容差**（跨平台位级一致只对无接触驱动的情形要求）。
3. **不碰热路径默认档**：新增力/耦合一律走 `Option`/`0 = 关` 的旋钮（与 `settled_hold_iterations` 同款先例）。
4. **判据先于实现**：每项先写"什么读数算通过"，再动手。

## 1. 风场（M-W1）——已有面元气动的推广

| 项 | 内容 | 判据 |
|---|---|---|
| W1.1 | **时变风场**：均匀风 + 阵风（正弦/1/f 噪声，种子确定） | 静止板在阵风下的力矩时间序列与解析包络一致（包络幅度 ±5%） |
| W1.2 | **空间剪切风**：高度分层 + 涡旋场（Taylor–Green 或 Rankine 涡） | 单个粒子在给定涡场里的轨迹闭合误差 < 1%（无阻尼时） |
| W1.3 | **风压→压力场**：把面元气动接到 PBF 流体的边界（风生水面波纹） | `m5_dam_break` 加风后静水面的均方波高随风速单调，且无风时**逐位不变** |

## 2. 降水与积水

| 项 | 内容 | 判据 |
|---|---|---|
| W2.1 | **雨滴粒子**（非流体）：批量下落 + 与刚体/布的冲量 | 布面在给定雨强下的下沉量与解析（质量通量）一致 ±10% |
| W2.2 | **地面湿度**（三值栅格！）：`干燥 / 潮湿 / 积水` 三态，目标坐标直接落 `trit` 的三值语义 | 三值栅格的守恒：雨强积分 = 状态迁移总量（逐格对账，误差 0） |
| W2.3 | **积水→流体**：湿度超阈值处生成 PBF 薄层 | 生成量与阈值超调量单调；关闭时逐位不变 |

> W2.2 是这条线里**唯一**天然三值的地方（干/湿/积水），也是 `trit` 能被真正吃进来的一处；
> 其余项都不该硬套三值。

## 3. 冰雪与低温

| 项 | 内容 | 判据 |
|---|---|---|
| W3.1 | **积雪覆盖**：体素/高度场上的可堆积层（质量守恒 + 休止角） | 堆积休止角落在 30°–40°；质量守恒误差 < 0.5% |
| W3.2 | **冻结/融化**：流体粒子与雪的相变（简化：两态 + 能量阈值） | 相变前后总质量守恒（逐位），相变不引入 NaN |
| W3.3 | **冰面摩擦**：刚体↔冰的摩擦系数档位 | 斜面滑出角与 μ 的解析关系 tanθ = μ（双向实测） |

## 4. 极端事件（破坏耦合）

| 项 | 内容 | 判据 |
|---|---|---|
| W4.1 | **龙卷风**：Rankine 涡 + 抬升力，作用于刚体/碎片/布 | 碎片在涡核半径内的稳态轨道周期与解析一致 ±15% |
| W4.2 | **风暴潮 / 巨浪**：海洋域的极端波（非线性波列） | 浮体在给定波列下的横摇幅值与线性理论差 < 20%（并记录非线性偏差） |
| W4.3 | **冰雹冲击**：高速小质量体 → 既有破坏域（Voronoi 预断裂） | 撞击深度 vs 速度满足能量标度 `d ∝ v^{2/3}` ±10% |

## 5. 每项都要有的"测试"（不是可选项）

1. **金样**：每个 W 项至少 1 条金样（场景 + 冻结读数 + 有界容差），进 CI 阻断。
2. **反证**：每条判据要有一个"把特性关掉就必红"的变异（门只证明它跑到的那一支）。
3. **默认档零影响**：新增项默认关时，现有 14 条金样与 determinism 必须逐位不变。
4. **性能**：每项给出开/关的 ms/tick（同机同场景），并说明是省带宽还是省指令。

## 6. 顺序建议

W1.1 → W1.2 → W1.3（风是最便宜、复用面元气动最多的一条）→ W2.1 → W3.1 → W3.3 →
W4.1 → W4.3 → W2.2/W2.3（三值湿度，等 `trit` 的栅格接口稳定后再做）→ W4.2。

> 与 `docs/PHYSICS-INVARIANTS.md §4.4` 的关系：天气线是**加面**，不替代 VBD/确定性/GPU 下沉
> 那三条主线；每条都要在 §4.4 的四条不变量下自证（能量、确定性、可回放、默认档不变）。
