# 性能复核（2026-09-27）—— 候选清单 + 一次实测 + 「别再试」护栏

> 起因：通读 `feat/solver-limits`（`9960256`）后的性能专项复核。
> **本文不改任何引擎代码**——本仓纪律是「无实测净收益的改动一律回退」+ ADR 0002 的
> ≥5% 收益律。唯一新增的**代码**是一个成本探针
> （`crates/vxl-phys-narrow/tests/clone_cost_probe.rs`，只报数不断言），它产出 §1 的表。

## 0. 口径（先说清为什么这次没有"顺手优化"）

四条把"看起来该优化"变成"不能收"的硬约束：

1. **本机分辨力不足**：`KNOWLEDGE.md` 记过同一份代码在相隔数十分钟的窗口测出 ±3–5% 漂移，
   并发构建下可达 ±25%，结论是「**<5% 的单项优化在当前环境下无法与噪声区分**」。
2. **≥5% 收益律**（ADR 0002）：进热路径的改动必须先给**实测上界**，不是估计。
3. **小对象分配主导的量要点"引擎真实形状"**：本次实测证明，同一份数据"单个 clone"与
   "8 个并存"差 **5–20×**（§1.2）——只测单点会得出相反结论。
4. **本仓的性能杠杆已高度枯竭**：`EXPERIMENTS.md` / `OPEN-PROBLEMS.md` 里有大量
   "做了、量了、回退了"的**已否证**记录（§4 汇总）。重走一遍是纯浪费。

## 1. 本次实测：窄相并行路径的 `clone()` 成本 —— ✅ 有读数，❌ 未达门槛

### 1.1 机制（读码定位）

`crates/vxl-phys-narrow/src/entry.rs` 的并行分块闭包里，**每个块**做一次
`let mut np = this.clone();`（`DefaultNarrowPhase` 是 `#[derive(Clone)]`）
⇒ 每 tick 每子步 × 块数（块数 = `min(threads, pairs/2048)`）次**深拷贝**。

而该结构体装的**不只是 scratch**（字段见 `crates/vxl-phys-narrow/src/phase.rs`）：

| 字段 | 是什么 | collide 期间 |
|---|---|---|
| `hulls: HullStore { hulls: Vec<ConvexHull> }`（`store.rs`） | **全部注册外壳的点云**（每个 `ConvexHull` 内含 `Vec<Vec3>`） | **只读** |
| `compounds: CompoundStore { items: Vec<Vec<CompoundChild>> }`（`store.rs`） | **全部复合体子形状表** | **只读** |
| `polys` / `poly_index` | 世界多面体**缓存**（`support.rs::poly_for` 会 push/insert） | 读写 |
| `axes` / `clip_in` / `clip_out` / `cand` / `kept_buf` / `ref_v` / `poly_a` / `poly_b` / `kids_buf` / `hull_pts` | scratch | 读写 |

⇒ 前两类的逐块复制**在结构上是浪费**，且成本随**注册量**增长、**不随本子步的对数增长**。
它一直没被注意到的原因很清楚：主力性能场景（`m1_scale` 的 10 万盒）**一个外壳都没注册**
⇒ clone 近乎免费（实测 0 外壳 = **0.0008 ms/tick**）；只有外壳密集场景才显现。

### 1.2 读数（`clone_cost_probe.rs`，本机 release；预热 1 次 + 3 轮取最小）

| 外壳数 | 单个 clone µs | **8 个并存/趟 µs** | spread | 外推 ms/tick（×2 子步） |
|---|---|---|---|---|
| 0 | 0.028 | **0.408** | ×1.01 | **0.0008** |
| 64 | 2.544 | **109.3** | ×1.15 | **0.22** |
| 256 | 58.5 | **399.9** | ×1.13 | **0.80** |
| 1024 | 34.9 | **1416.2** | ×1.11 | **2.83** |

- **"8 个并存"才是引擎形状**：`n_chunks = min(8, pairs/2048)`，8 个 clone 同时存活再一起释放。
- **单点与批量的差是要点**：1024 外壳下"单个 clone" 34.9 µs，而批量摊到每个是 **177 µs**（÷8）
  ——活内存 ×8 ⇒ 缺页/分配器复用变差 ⇒ **只测单点会把这个成本评低 5×**。
- ⚠️ 探针另有一档"先跑一遍 `collide` 把 `polys` 缓存填起来再量"，但它**没能隔离出缓存的贡献**：
  那次读数反而更低（256 外壳 209.8 vs 399.9 µs），因为两次运行的**分配器热度不同**
  ⇒ 该档只作留痕，**判据只用"8 个并存"这一列**。

### 1.3 判定：**现在不做**（附触发阈值）

拿本仓已录的窄相读数当参照（`arena_bench` 三角网探针 ≈ **22 ms/tick**）：

| 外壳数 | clone 占窄相 | 结论 |
|---|---|---|
| 0（`m1_scale` 等主力场景） | ~0% | 无需动 |
| **64（≈ 该探针当前的 ~67 个外壳体）** | **~1.0%** | **低于 ≥5% 门槛 ⇒ 不做** |
| 256 | ~3.6% | 仍低于门槛 |
| **≳ 400** | **≥5%** | **届时值得做** |

- **补丁形状（留档，届时照做）**：把两个只读仓库改成 `Arc<HullStore>` / `Arc<CompoundStore>`
  ⇒ `#[derive(Clone)]` 对它们退化为引用计数 +1；注册走 `Arc::make_mut`
  （注册发生在 collide **之外**、此时 refcount = 1 ⇒ 不触发拷贝）。
  **逐位安全性**：两者在 collide 期间只读 ⇒ "共享"与"各持一份"的读结果完全相同
  ⇒ 属本仓偏好的「**逐位安全**」路线（同表达式、同求值顺序）。
- **验收配方（须在安静机上）**：
  `bash scripts/ab_perf.sh <旧ref> 3 '<grep 模式>' <跑外壳密集场景的命令>`
  ——必须用**外壳密集**场景（`arena_bench` 三角网探针 / `showcase`）；
  在 `m1_scale` 上量这个改动**必然测不出**（那里 0 外壳）。

## 2. 复核过、确认**不是**杠杆的

- **`record_impacts` 无条件每子步跑**（`crates/vxl-phys/src/world_step.rs:325-328`）：
  它遍历**全部流形**、只为 provider 对快照冲击（供破坏管线）。非 provider 对整条 `continue`
  ⇒ 每次迭代 ~2 次形状读 + 一次 match（~5–10 ns）。按 10 万流形 × 2 子步估 **1–2 ms/tick**，
  对 8B 的 330 ms 是 **0.3–0.6%**、对瞬态 187 ms 约 1% ⇒ **不够格**。
  （顺带确认它不参与哈希：`impacts` 不在 `state_hash` 里、物理也不读它。）
- **窄相每块 `Vec::with_capacity(out_hint/n_chunks + 8)`**：每趟 collide 的"块数"个分配，
  且上游已有 `out.reserve(out_hint)` ⇒ 拼接不再重分配。量级远低于 §1。
- **三处并行门槛数值不同**（`broad` 32768 / 窄相 2048 / `ScopedPool::min_parallel` 2048）：
  `broad` 的 32768 是**已有标定注**的（30 ns/AABB vs ≈0.6 ms 启动），窄相每对是 **µs 级**
  ⇒ **三者不是同一个量的三个值，本就不该统一数值**。同批改动已把窄相门槛命名并写明
  这层关系（`NARROW_MIN_PARALLEL`）。

## 4. 护栏：已被本仓实测否证的性能路线（**勿重做**）

逐条都有 commit 与读数，出处见 `EXPERIMENTS.md` / `OPEN-PROBLEMS.md` / `KNOWLEDGE.md`：

- **"减指令数"类**：预积角向量、取模换分支、裁剪定长数组、距离表复用、关节热启动、扫掠减档
  —— 6 次**全否**；同一段里唯一落地的是「**减工作量**」（去每流形一次堆分配 −4.1%、
  跳过零冲量接触点 −7.3%）。判据：**先问减少的是"工作量"还是"指令数"，只做前者**。
- **求解环内的数据布局**：64B 行 / 32B 行 / 冷热分离 / 点数据扁平 arena / 快速哈希
  —— 全否（含 **−20% / −25%** 的**反向**读数；根因是原实现的散查是流式、预取友好）。
- **宽节点树**（`wide.rs` / `bvh8.rs`）：孤立对拍全胜、**生产接入净负**
  （候选量 5.9×、查询 +90%、宽相合计净亏 6.4 ms/帧）⇒ 降级为研究资产（ADR 0001）。
- **岛批量 4-lane 交错**：修掉 lane 相位耗尽 bug 后**逐位透明**，但实测仍 **−3% 反向**。
- **同岛 4-lane（Jacobi 化）**：量化上界 ≤10% ⇒ 不开工。
- **接触点聚类裁点**：前提被否证——**点数是承重件**（4→3 令末态动能 +80%、最深穿透 ×3.9）。
- **降迭代**：iters=8 塔 KE 32.8 万 J、iters=4 塔崩 ⇒ 该杠杆已关闭。
- **"检测每步一次"**：默认档门红 + 金样红 + **还慢 29%**（双输，且非取舍）。
- **warm 表换快速哈希**：33.51 → 33.64 ms（噪声内）⇒ 成本在**访存**不在哈希。
- **岛内染色 / 大岛切批**：先算账即否（工作集驱动的"每流形成本"变化 11–18×）。
- **"加 per-body 数组去散查"**：两次实测更慢（−20%/−25%），已回退。
