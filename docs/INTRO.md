## 四条技术主张（每条都带判据）

### 1. 逐位确定性，而且跨编译器验证

固定 60 Hz + 严格 f32 + 无 fast-math + 归约有序。CI 里跑 **3 个编译器 × 2 个架构**
（MSVC / GCC / Clang+LLD 各自在 x86_64，GCC 另跑 aarch64-qemu）并要求**末态哈希全等**：
`0xc0dfc6f4bb0382c2c47a1eab66c575bb`。

为什么重要：确定性 = 任何 bug 都能**逐位复现**，任何回归都能二进制级定位。
这是 AI 训练仿真数据的硬需求——数据质量直接决定模型质量。

### 2. 13 项金样，分两类判据

- **位模式**（要求 `f32::to_bits` 完全相等）：浮体、帆、系泊、布、绳索、坍塌
- **有界容差**（实测跨平台最大差 `1.2e-4`，取 `1e-3`）：车

为什么第二类必须放宽？因为车是**接触驱动的混沌系统**，180 tick 足以把 1 ulp 放大到末态
位模式不同。**这不是妥协，是被 CI 逼出来的结论**——去掉全部三角函数后差距仍在。

### 3. 物理 bug 有分类，不是「感觉不对」

`docs/PHYSICS-INVARIANTS.md` 把物理 bug 定义成五类可判定的东西：**发散 / 穿透 /
能量注入 / 非确定性 / 静默失效**。每一类都指向仓内真实存在、CI 里真在跑的测试。

刚修掉的一个典型案例：`Distance` 关节的冲量符号写反，导致迭代**发散**——
`v·n` 序列 `0 → −7.2 → −21.6 → −50.4 → … → −914`，间距一步从 `0.8` 砸到 `0.0129`。
一个符号，整条约束链失效。修完间距单调收敛到 `0.5012`。

### 4. 23 个 crate 的分层，但依赖注入是 trait

`BroadPhase` / `NarrowPhase` / `ForceField` / `StateHash` / `PhysGpuBackend` 全是 trait，
自定义实现不改核心。默认最小管线 = core + broad + narrow + solver + integrate + island。

## 诚实的部分

| 没做到的 | 现状 |
|---|---|
| 10 万 + 10 万 30 FPS | 差 **9.9×**，需要结构性重做（不是调参） |
| 统一求解器（软体与刚体共用一个求解系统） | **已设计评审，结论不建议做** —— 2.4 万行、9 项金样全变、FLIP 纳不进来 |
| 布料的 GPU 档 | `implementation: absent` |
| 大面积压力域（压力域 / 机械传动） | 骨架：`mech` 34 行、`marine` 29 行、`wheeled` 92 行 |
| 神经网络物理代理 | **明确不做** —— 天生违反能量不增与逐位可回放两条 |
