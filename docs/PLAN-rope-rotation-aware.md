# PLAN：绳↔刚体耦合的**转动感知**（2c）—— 重启用角反作用的前置

> 立项依据：`SURVEY-SOFT-CLOTH-AND-CONVERSION.md` §8.4.10（为什么角反作用被停用）、
> §8.4.19/§8.4.25（摩擦口径的两次教训）、§8.4.27（睡眠体）、§8.4.28（角冲量注入契约已钉住）。
> **一句话**：现在接触模型**看不见转动**（`body_disp` 只跟踪平移、摩擦只用 `b.linvel`、
> `crossed_face` 用冻结的 `rot`）⇒ 角反作用一旦启用，体转起来的运动会完全落在模型之外
> （实测单点接触 `|ω|` 一 tick 到 5~8 rad/s ⇒ 接触立刻丢失 ⇒ 盒子被甩下去）。
> 所以**先补"看得见转动"，再谈启用**。

## 判据（**先判据后实现**；每一步落地前先能跑）

- **零换代门（每一步都要过）**：既有三条"托住"判据（`rope_minimal` ② / `rigid_coupling_gap::box_on_rope_is_held` /
  `rope_coupling_robustness::rope_holds_box_across_parameters` 14 格）+ 摩擦阈值两条 + **三个冻结哈希**
  （`5a2440914067fe15` / `faf4d9e7443ddbef` / `36eaadb902cc8481`）**一字不动**。
  依据：现有场景里绳上的盒 **`ω ≡ 0`**（实测），转动感知在 `ω = 0` 时应**恒等**。
- **2c-1 新判据**：给定**预置 `ω`** 的盒子，其**接触几何**必须按转动更新 —— 做法：盒子上方落绳、
  盒子带固定 `ω`（门面可直接写 `bodies.angvel`），钉住一个**轨迹读数**（位模式或固定小数的 `(y, x, 倾角)`）。
- **2c-2 新判据**：同上场景，**摩擦的滑移量取接触点速度**（`linvel + ω × (q − x)`）⇒ 钉住一个读数，
  并说明"若仍取 `linvel`，该读数会怎样不同"（做成对照，否则判据分辨不出口径）。
- **2c-3 新判据**：**偏置负载下该转的转** —— 绳只托住盒的一半（或盒重心偏置）⇒ 盒子倾角随时间的
  稳态值应约等于 `Σ r×J / I_zz` 的解析估计（容差按离散化给）；并同时断言**取消托住判据与冻结哈希仍不动**。
  （若 2c-3 让既有判据动了 ⇒ **先别调参数**，回查角冲量的接触点与钳位口径。）

## 代码触点（按依赖顺序）

1. **代理多一个量**：`vxl-phys-soft::RigidProxy` 加 `angvel: Vec3`；门面 `rope_pass` 填
   `self.bodies.angvel(i)`（静态/睡眠体填 0 —— 与 §8.4.27 的"睡眠=静态"同一口径）。
2. **虚拟位姿带转动**（`rope.rs::project_body_contacts`）：`body_disp` 旁边加**虚拟角**
   （`body_rot_disp: Vec3`，子步内 `+= ω_virt·h`）；`vpos` 之外再维护 `q_virt`（由 `b.rot` 按
   `body_rot_disp` 积分）。`box_hit` 的全部几何改用它 —— 含 `crossed_face` 的**两个位姿各自带朝向**
   （`vpos_prev` 也要配 `q_prev`）。
3. **摩擦取接触点速度**：`dp = pos[i] − prev[i] − v_point·h`，其中
   `v_point = linvel + angvel × (q − vpos)`（`q` 是 `box_hit` 给的接触点）。
4. **反作用与虚拟状态推进**：已有 `impulse`/`torque = r × impulse`；新增
   `body_rot_disp[j] += (I⁻¹·torque)·h`（与 `body_disp` 对称），并**按已钉住的契约**把 `torque` 交给门面：
   `bodies.torque[b] += r.torque * (substeps / dt)`（判据：`angular_impulse_contract`）。
5. **角冲量钳位（关键）**：与线速度那支同口径 —— 角冲量也要按"消掉本次**接触点**接近速度"钳位
   （否则单点接触一次踢击就把 `|ω|` 打到 5~8 rad/s，§8.4.10 的实测）。

## 分步与回退（每步独立、可单撤）

| 步 | 内容 | 落地判据 | 回退 |
|---|---|---|---|
| **2c-1** | 代理 `angvel` + 虚拟位姿带转动 | 零换代门 + 2c-1 新判据 | 单提交撤销；`ω=0` 时恒等 ⇒ 无副作用 |
| **2c-2** | 摩擦取接触点速度 | 零换代门 + 2c-2 对照判据 | 同上 |
| **2c-3** | 按契约重启用角反作用 + **角冲量钳位** | 零换代门 + 2c-3 新判据 | 同上；若既有判据动了则**先撤 2c-3** 回查 |

## 风险

- **风险 A（单点接触的力臂）**：`hit = 1` 时力臂 ≈ 0.3 m、`I_zz` 小 ⇒ 角冲量放大明显 ⇒ **必须**做第 5 条钳位。
- **风险 B（入口面缓存与转动）**：缓存存的是**本体系**面号（这点已经对），但"进入时的那张面"在体转动后
  可能不再是支撑面 ⇒ 需要一条闸：**转动超过阈值（如 `radius / max(半长)`）就释放缓存**，让它重新穿越判定。
- **风险 C（摩擦棘轮复发）**：§8.4.19 与 §8.4.25 两次栽在切向口径上 ⇒ 转动项的摩擦必须**同一次**就把
  "接触点速度 + 锥口径 `μ·w_p·λ`"写对，别分两步试。
- **风险 D（既有哈希）**：唯一可接受的结果是"`ω = 0` 场景逐位不变"；一旦动了就说明某处把转动项
  漏进了平移路径 ⇒ 停手回查，别用重冻基线糊过去。

## 不做什么（写清边界）

- **不做**刚体↔刚体、布↔刚体的转动耦合（那是各自的切片）；
- **不做**绳的内部转动（绳仍是**点链**，粒子无朝向；"绳要有表面/厚度"是另一条线，见 §8.4.1）；
- **不做**角速度的睡眠/唤醒策略调整（沿用既有 `awake`，睡眠体对软体域呈现静态）。
