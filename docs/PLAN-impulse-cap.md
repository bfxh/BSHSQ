# PLAN-impulse-cap —— 法向冲量限幅/耗散（P18 最后一条杠杆，2026-10-28 立项稿）

> 一句话：窄相只能选**法线方向**，选对了就把杆甩飞（C2：`min|φ|` 0.000° 但薄板档心漂 50.58 m）；
> 所以「抓住但温和」只能靠**限制每个 tick 注入的法向冲量**——这是求解器侧的量，窄相碰不到。

关联：`PLAN-corner-normal.md`（C1/C2 否证、路线关闭）、`EXPERIMENTS.md` E-corner-normal-1/2、
`OPEN-PROBLEMS.md` P18、`KNOWLEDGE.md` §1.9、`adr/0004`（换代账）。

## 3. 候选（三条，按侵入性排序；每条单独 A/B，默认关）

### D1 · 单 tick 法向冲量上限（**首选**，最小侵入）
给 `new_pn` 加上界：`new_pn = clamp(…, 0, cap)`，`cap = k · nmass · v_approach_ref`，
其中 `v_approach_ref` 取**本 tick 该点的接近速度**（`max(0, −vn)`）而非全局常数。

- 语义：一个 tick 最多把接近速度削掉 `k` 倍（`k ≥ 1` 时等价于现状；`k < 1` 时"软化"）。
- 期望：`k` 从 1 往 0 扫，应出现「`min|φ|` 先降到 3.274° 以下、心漂仍 ≤ 1 m」的窗口。
  若不存在窗口（同 C1 的阶跃），直接止损。
- 触点：`island.rs:87` 一行 + `SolverParams` 加 `impulse_cap_k`（默认 `f32::INFINITY` = 现状逐位不变）。
- 风险：限幅会削弱**密堆支撑**（法向冲量是唯一的支撑来源）⇒ 必须查堆叠档。

### D2 · 接触恢复/耗散按速度分档
把 `e`（恢复系数）从常量改成「按接近速度分档」：低速弹、高速不弹（`e(vn) = e0 · exp(−|vn|/v_ref)`）。
- 语义：高速撞击不反弹（减少甩飞），低速保持弹性。
- 触点：`constraint.rs:272` 的 `bounce` 计算。
- 风险：改的是**反弹**不是**冲量总量**；对 P18 这种掠擦可能无效（`vn` 本来就近 0）。

### D3 · 角向冲量上限（滚阻/自旋阻尼的"新形态"）
只对**接触点相对质心的角向分量**限幅，不动平动分量。
- 语义：允许杆被推开（平动），但不允许接触把大量角动量一次换走/换入。
- 触点：`island.rs` 冲量施加处（需按 `r × n` 拆分）。
- 风险：历史两族耗散已否证，这是第三种形态，风险最高；只有 D1/D2 都失败才做。

**顺序：D1 → D2 → D3。**

## 4. 判据（预注册，缺一不可）

目标档 `ccd_rot_probe`「小柱」，`ccd=开`：

| 指标 | 基线 | 通过线 |
|---|---|---|
| `min|φ|` | 3.364° | **< 3.274°**（柱面角，必须真的被角点挡住） |
| 杆心最大漂移 | 0.7109 | **≤ 1.0 m**（不得比现状更差超过 40%） |
| 末 `|ω|` | 10.13 | **< 10.13**（必须下降；C2 失败就败在这条） |
| 峰值埋深 | 0.0000 | **≤ skin（0.02）** |

**回归面（任一红即不落）**：
- `ccd_rot_probe` 另外两档（正面薄墙 / 立面薄板）**心漂不得劣化 >10%**（C2 就是死在这条）；
- `m0_gates` 门槛档 `max_wake_flips < 1.0/s`、`verdict PASS`；
- 三哈希换代**逐条登记**（`determinism` / `m0_gates` 压力档 / `m3_collapse`），按 `adr/0004` 重冻；
- 金样：`col45` 横向 ≤ 0.01、`pile5` ≤ 0.01、`tower25` 横向 ≤ 0.05 且超 slop 点数 = 0；
- `simd_matches_scalar_bitwise`、`gpu_narrow_probe`、`gpu_band_probe` 仍绿。

## 5. 止损（预注册，先写死）

任一条成立即**回退，不留开关**：

1. `min|φ|` 扫遍 `k ∈ (0,1]` 都没有 **同时** 满足「< 3.274°」与「心漂 ≤ 1.0 m」的档（阶跃 ⇒ 该自由度不可行）；
2. 末 `|ω|` 不下降（与 C2 同一失败模式）；
3. 任一回归档心漂劣化 > 10%；
4. 密堆压力档最大深度比现状深 > 20%（拿支撑换演示，不值）；
5. 需要给求解器传**速度以外的全局状态**（如接触历史）才能成立 ⇒ 属另一类模型，另立项。

## 6. 分片

- **K1**：`SolverParams::impulse_cap_k`（默认 `f32::INFINITY`）+ `island.rs` 一行 clamp；默认档逐位不变。
  跑 `k ∈ {0.9, 0.7, 0.5, 0.3, 0.1}` 曲线。
- **K2**：按曲线判断是否存在可用窗口；有则查回归面，无则止损。
- **K3**：若 D1 无效，做 D2（恢复系数按速度分档），同样默认关。
- **K4**：D3 仅在 D1/D2 均失败时做。
- **K5**：定案后升 `PhysConfig` 字段 + 换代账 + 金样重冻 + `gate_all.sh`。

## 7. 边界（现在就能说死的）

- 限幅只保证「**不甩飞**」，不保证「**卡住**」：`min|φ|` 是否下降取决于接触几何是否真的产生角点载荷。
  若 D1 的曲线显示「心漂压住了但 `min|φ|` 仍 3.364°」，说明杆只是被温柔地推开，
  **P18 应改判为「正确的掠擦行为」并关闭**，不再追求"卡住"。
- 这条路线不改变 `EXPERIMENTS.md` 里已否证的两族耗散结论；D2 与它们是不同形态（改 `e(vn)` 而非加阻尼项），
  但仍须独立 A/B。
