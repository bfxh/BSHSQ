# 音色表（S3，`docs/ROUTE.md` §3.2）：材质槽 → 音色组 id。
#
# 格式：一行一条 `<材质槽> -> <音色组 id>`；整行 `#` 开头是注释；空行忽略。
#   不支持行内注释——一行要么整行注释，要么恰好一条映射。
# 语义：材质槽是**物理**侧概念（= `bodies.material[body]`，即 cue 流里的 `mat` 字段）；
#   音色组 id 是**资产**侧的不透明编号，本域只搬运、不解释。
#
# 判据（**显式拒绝**）：本表没登记到的材质槽**不会回落"默认音"**——`sense_dump ... <本表>`
#   会打印报错并**退出码 2**，报出缺的是哪个槽。改音效包 = 只改这张表，不动引擎。
#
# 示例场景（`cargo run -p vxl-phys-sense --bin sense_dump -- 300 64 16 impact <本表>`）里的盒子
# 未显式挂材质 ⇒ 全部落在槽 0，所以下面这一条就够它跑通。
0 -> 100

#   2 -> 120   # metal
